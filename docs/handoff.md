### Препятствие, на котором остановились

**Кабель Рафаэля не даёт данные.** `flutter devices` его не находит,
`devicectl` показывает `unavailable`, а `system_profiler SPUSBDataType`
не видит ни одного iPhone на шине USB вовсе. Xcode при этом был закрыт —
дело не в нём.

Проверять по порядку: переподключить кабель плотно с обеих сторон →
подтвердить «Доверять этому компьютеру» и разблокировать телефон →
другой кабель или другой порт (кабель от зарядки часто только питает).

**Запасной путь, если возиться не хочется:** собрать Рафаэля по
беспроводу — он числится в сети отдельным устройством. Медленнее минут на
пять, результат тот же. Порядок «сначала Рафаэль, потом Teymur»
сохранить.

### Как собирать

```
pgrep -f "Xcode.app/Contents/MacOS/Xcode"      # ДОЛЖНО быть пусто
stdbuf -oL -eL flutter run -d <device-id> > build_X.log 2>&1
```

- **Xcode.app обязан быть закрыт.** При открытом Xcode запуск на Teymur
  сорвался сегодня с `Error starting debug session in Xcode: Timed out
  waiting for CONFIGURATION_BUILD_DIR to update` — приложение не встало
  вовсе. После закрытия та же сборка прошла.
- `flutter run` **сам не завершается**. Ждать его выхода бессмысленно:
  признак готовности — строка `Flutter run key commands.` в логе, после
  неё отцепляться (`pkill -f "flutter run -d <id>"`, код 144 — это свой
  же pkill, не сбой).
- Вывод собирать **построчно в файл**, не через `| tail`: иначе лога не
  будет вовсе до конца процесса.
- `Running Xcode build...` идёт **без перевода строки** — лог не растёт,
  и это нормально. Живость сборки проверять по процессам `clang`, а не
  по логу.
- Времена сегодня: Рафаэль по кабелю 1096 с компиляция + 353 с установка
  (полная пересборка нативной части); Teymur по беспроводу 52 с + 425 с
  (нативное уже в кеше).

### Что проверять после установки

**Пункт 3, вдвоём.** Рафаэль в чате с Teymur жмёт «İş təklif et»:

1. Открывается лист — заголовок **«İş təklifi»**, кнопка **«Təklifi
   göndər»**, у «Yer» и «Qeydlər» подпись **«vacib deyil»**.
2. Закрыть свайпом не заполняя — предложение **не должно появиться ни у

3. Открыть снова, что-нибудь ввести, закрыть свайпом — должен спросить

4. Попробовать выбрать вчерашнюю дату и отправить — должно отказать

5. Заполнить и отправить: у Teymur сразу дата, тип, место, **заметки

## 6. Правила, выведенные за эту сессию

- **Отчёт механизма и проверка механизма должны быть разными обходами.**
  Сборщик сирот сам себе сказал «удалил двоих законно»; поверить этому
  можно было только отдельным проходом по всей базе, ищущим ссылки на
  удалённое. Иначе проверяется самосогласованность, а не факт.
- **Комментарий у числа держит запрет крепче, чем реестр.** У
  `DEFAULT_MIN_AGE_MS` прежний текст сам приглашал сузить окно
  («реальный разрыв — секунды»), и правило снялось бы при первом чтении
  кода. Причина должна лежать рядом с числом.
- **Локальная запись возвращается в поток раньше, чем закроется форма.**
  Firestore отдаёт её из кеша немедленно. Всё, что различает «своё» и
  «чужое», должно объявляться ДО записи, а не после.
- **Ключ по подписи на экране ломается на втором экране.** Подписи строк
  у двух карточек разные; ключевать надо по имени поля.
- **Проверка «на глаз» не отличает старую сборку от новой.** Список
  процессов на телефоне одинаков. Доказательство — либо поведение,
  которого старая сборка не умеет, либо строка `Flutter run key commands`
  в логе.
